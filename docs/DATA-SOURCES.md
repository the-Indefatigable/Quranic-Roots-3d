# Where QuRoots' data comes from

The record of every dataset on QuRoots: where it came from, how it got into the database, the
terms it is under, and what we do to comply. Keep this current whenever a source changes. It is
the answer to "where did this data come from?", and the git history of `scripts/` is the evidence.

Last reviewed: 27 October 2026. This is a plain-language record, not legal advice.

## Rules going forward

1. **Every new dataset gets a row here before it ships**, naming its source, terms and the script that loaded it.
2. **Never take a copyrighted translation or tafsir** without written permission. Link out instead.
3. **Corpus-derived data is credited, never claimed as ours.** Our own work is the teaching on top of it: the path, lessons, explanations and reviewed meanings.
4. **Keep the import scripts in git.** They show the data was built from named sources, not scraped from a competitor.
5. **Corrections are public.** Errors reported to salam@quroots.com get fixed and noted.
